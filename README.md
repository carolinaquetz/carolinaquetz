# Airport Portuguese Practice

Landing page estática em HTML e CSS puro.

## Publicar no GitHub Pages

Em **Settings → Pages**, selecione **Deploy from a branch**, a branch `main` e a pasta `/(root)`.

Antes de publicar, substitua `PASTE_HOTMART_CHECKOUT_LINK_HERE` no `index.html` pelo link real do checkout e adicione as URLs/imagens nos espaços indicados.
